# Pico_OLED_Arcade
An OLED module controlled by a Raspberry Pi Pico with fun games for the 4th week of Half-Life.

This project is a gaming system controlled by a Raspberry Pi Pico, shown on an SSD1306 OLED display. It has 5 buttons: up, down, left, right, and select. It contains MicroPython games obtained from YouMakeTech's repository, PicoRetroGamingSystem: https://github.com/YouMakeTech/PicoRetroGamingSystem/blob/main/README.md

The PCB has the Raspberry Pi Pico, the OLED display, a few resistors and capacitors, the 5 tactile switches, a piezo buzzer for sound effects, and an I2C connector for optional sensors.
